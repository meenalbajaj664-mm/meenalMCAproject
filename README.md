# MEE SHOP+

This is a small demo e-commerce project (HTML, CSS, JavaScript) created for the `meenalMCAproject` repository.

What is included:

- index.html — the main page
- styles.css — basic styling
- script.js — simple cart functionality using localStorage

How to run locally:

1. Clone the repository or download the files.
2. Open `index.html` in a browser.

Notes:

- This is a starter template. You can extend it by adding product data, real images, a backend, user accounts, and payment integration.
